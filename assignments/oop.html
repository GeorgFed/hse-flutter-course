Продуктовая постановка

Приложение хранит локальный каталог товаров и получает новую версию с бэкенда. Нужно найти id товаров, которые добавились, исчезли или изменились. Затем приложение сможет обновить только нужные карточки, а не перестраивать весь каталог. После синхронизации покупатель должен иметь возможность найти товары по названию, категории и цене; реализуйте для этого обязательный метод поиска.

Что должно получиться

старый List<Product> ─┐
                     ├─→ Map по id ─→ Set изменившихся id
новый List<Product> ─┘

Основной результат — корректная модель Product, сравнение списков, индекс Map, множество Set и отфильтрованный, отсортированный список товаров. Ошибка и логирование находятся в одном понятном месте.

ProductCartManager описывает четыре операции: сравнение списков, построение индекса, поиск изменений и фильтрацию каталога. Класс реализации студенты создают самостоятельно и возвращают из createProductCartManager(). Внизу того же lib/main.dart уже находится пример данных и вывод результата в консоль.

Выполняйте сверху вниз

Шаг 1. Сравнение Product

Переопределите operator == и hashCode.

  • сравните id, name, priceRubles, nullable category и tags;
  • tags — это список, поэтому сравнивайте его содержимое через ListEquality;
  • одинаковые товары обязаны иметь одинаковый hashCode;
  • проверка с Set<Product> покажет, согласованы ли equality и hash.

Шаг 2. Сравнение двух списков

Реализуйте sameProductList(...) через DeepCollectionEquality.

Обычное выражение firstList == secondList сравнивает два объекта List, а не их элементы. В этой задаче порядок товаров считается значимым.

Шаг 3. Индекс через Map

Реализуйте indexById(...):

  • ключ — Product.id, значение — Product;
  • повторяющийся id — некорректные входные данные;
  • перед FormatException запишите понятный лог с проблемным id;
  • после успеха залогируйте число товаров;
  • верните read-only Map.

Это единственное обязательное место обработки ошибки.

Шаг 4. Изменения через Set

Реализуйте findChangedIds(...):

  • постройте индексы старого и нового каталогов;
  • объедините их ключи в Set<String>;
  • оставьте id, для которых старый и новый Product не равны;
  • так автоматически найдутся добавленные, удалённые и изменённые товары;
  • не меняйте входные списки;
  • залогируйте итоговое число изменений.

Шаг 5. Поиск и фильтрация каталога

Зачем это продукту

Каталог уже обновлён. Покупатель хочет найти кофе, выбрать категорию и оставить товары, которые укладываются в бюджет. Реализуйте метод, который подготовит подходящие товары для показа на экране. Сам интерфейс приложения делать не нужно.

Правила

  • Поиск: query ищется как подстрока в Product.name, без учёта регистра. Пробелы в начале и конце запроса игнорируются. Пустая строка или одни пробелы не ограничивают выборку. По id и tags искать не нужно.
  • Цена: оставьте товары с ценой не выше maxPriceRubles, включая границу. null означает отсутствие ограничения. Отрицательный лимит даёт пустой результат: цены товаров неотрицательные.
  • Категория: оставьте товары с точно такой же category; сравнение чувствительно к регистру. null означает все категории, включая товары без категории. Фильтр «только без категории» не нужен.
  • Вместе: товар должен удовлетворять всем заданным условиям одновременно.
  • Порядок: сортируйте по цене по возрастанию; при одинаковой цене — по id через compareTo.
  • Исходные данные: не меняйте входной список, его порядок и товары. Верните новый список даже без фильтров. Можно считать, что id уникальны.

Где разобраться с where и фильтрами

  • Официальный учебник: фильтрация Iterable — объяснение и упражнения в DartPad.
  • Справка where — какие элементы остаются в результате.
  • toList — как получить отдельный список.
  • List.sort — сортировка и функция сравнения.

where оставляет элементы, для которых функция-предикат возвращает true, и возвращает ленивый Iterable. Вызов toList() собирает результат в отдельный список; сортировать нужно именно его.

Потренируйтесь на коротком примере, прежде чем переносить идею на товары:

final scores = [12, 5, 18, 9];
final selected = scores.where((score) => score >= 10).toList();
print(selected); // [12, 18]

В своей реализации поиска используйте where для отбора товаров. Тесты проверяют поведение; использование where и понимание Iterable объясните при сдаче.

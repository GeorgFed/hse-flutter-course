# Синхронизация каталога на Dart 3

## Зачем это делаем

Приложение хранит локальный каталог товаров и периодически получает новую версию с бэкенда. Нужно понять, какие товары добавились, исчезли или изменились, чтобы обновить только нужные карточки.

## Что нужно сделать

Интерфейс `ProductCartManager` уже описывает требуемые операции. Последовательно завершите модель `Product`, создайте собственный класс с `implements ProductCartManager` и верните его из `createProductCartManager()`:

1. Сравнение двух `Product` через `operator ==` и `hashCode`.
2. Глубокое сравнение двух `List<Product>`.
3. Индекс каталога `Map<String, Product>` с проверкой дублей и логированием.
4. Множество `Set<String>` с id изменившихся товаров.
5. Метод `searchProducts`: поиск, фильтры и сортировка через `where`, `toList` и `sort`.

В обязательной части нет records, patterns, async, Flutter и сложной архитектуры.

### Зачем это продукту

### Правила

- **Поиск:** `query` ищется как подстрока в `Product.name`, без учёта регистра. Пробелы в начале и конце запроса игнорируются. Пустая строка или одни пробелы не ограничивают выборку. По `id` и `tags` искать не нужно.
- **Цена:** оставьте товары с ценой не выше `maxPriceRubles`, включая границу. `null` означает отсутствие ограничения. Отрицательный лимит даёт пустой результат: цены товаров неотрицательные.
- **Категория:** оставьте товары с точно такой же `category`; сравнение чувствительно к регистру. `null` означает все категории, включая товары без категории. Фильтр «только без категории» не нужен.
- **Вместе:** товар должен удовлетворять всем заданным условиям одновременно.
- **Порядок:** сортируйте по цене по возрастанию; при одинаковой цене — по `id` через `compareTo`.
- **Исходные данные:** не меняйте входной список, его порядок и товары. Верните новый список даже без фильтров. Можно считать, что id уникальны.

### Пример каталога

| id | Название | Цена, ₽ | Категория |
|---|---|---|---|
| coffee | Кофе | 179 | Напитки |
| tea | Чай | 99 | Напитки |
| coffee-decaf | Кофе без кофеина | 249 | Напитки |
| cookie | Печенье | 99 | null |
| water | Вода | 50 | Напитки |

  Product(id: 'tea', name: 'Чай', priceRubles: 99,
      category: 'Напитки'),
  Product(id: 'coffee-decaf', name: 'Кофе без кофеина',

### Проверьте себя

В таблице показаны id в ожидаемом порядке. Функция возвращает сами `Product`, не строки.

| Параметры | Ожидаемые id |
|---|---|
| `query: ' КоФе '` | coffee, coffee-decaf |
| `query: 'кофе', maxPriceRubles: 200, category: 'Напитки'` | coffee |
| `maxPriceRubles: 99` | water, cookie, tea |
| `maxPriceRubles: 99, category: 'Напитки'` | water, tea |
| `query: '   '` или без параметров | water, cookie, tea, coffee, coffee-decaf |
| `query: 'сок'` | пустой список |
| `category: 'напитки'` | пустой список: категория сравнивается точно |
| `maxPriceRubles: -1` | пустой список |

Проверьте также пустой входной список. После вызова исходный `catalog` должен по-прежнему начинаться с `coffee`, затем `tea`: сортировка результата не должна переставлять товары во входе.

Такой вызов уже есть в готовом `main`; `manager` создан через `createProductCartManager()`:

```dart
final found = manager.searchProducts(
  catalog,
  query: ' КоФе ',
  maxPriceRubles: 200,
  category: 'Напитки',
);
print(found.map((product) => product.id).toList());
// Ожидается: [coffee]
```

В DartPad пример находится в `demoMain`. Проверяющий `main` вызывает его после прохождения всех 16 проверок.

### Где разобраться с where и фильтрами

- [Официальный учебник: фильтрация Iterable](https://dart.dev/libraries/collections/iterables#filtering) — объяснение и упражнения в DartPad.
- [Справка where](https://api.dart.dev/dart-core/Iterable/where.html) — какие элементы остаются в результате.
- [toList](https://api.dart.dev/dart-core/Iterable/toList.html) — как получить отдельный список.
- [List.sort](https://api.dart.dev/dart-core/List/sort.html) — сортировка и функция сравнения.

`where` оставляет элементы, для которых функция-предикат возвращает `true`, и возвращает ленивый `Iterable`. Вызов `toList()` собирает результат в отдельный список; сортировать нужно именно его.

Потренируйтесь на коротком примере, прежде чем переносить идею на товары:

```dart
final scores = [12, 5, 18, 9];
final selected = scores.where((score) => score >= 10).toList();
print(selected); // [12, 18]
```

В своей реализации поиска используйте `where` для отбора товаров. Тесты проверяют поведение; использование `where` и понимание `Iterable` объясните при сдаче.

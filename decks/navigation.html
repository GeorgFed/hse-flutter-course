191 · Стек экранов

Список ждёт результат и обновляет State

Dart
Future<void> openCity(City city) async {
  final result = await Navigator.of(context).push<City>(
    MaterialPageRoute<City>(
      builder: (routeContext) =>
          CityDetailsPage(city: city),
    ),
  );
  if (!mounted || result == null) return;
  setState(() => selected = result);
}
  • Тип результата: City?.
  • При null оставляем прежний выбор.
  • В части 4 вынесем построение маршрута в отдельный класс.

Запуск, обновление и полезные команды

flutter pub get

Разрешает зависимости из pubspec.yaml. flutter create уже запускает его; повторяем после изменения зависимостей.

flutter run -d chrome

Запускает выбранную цель. flutter devices показывает доступные устройства.

Hot reload: r · restart: R

Reload сохраняет State и не повторяет main/initState. Restart заново запускает Dart-приложение.

format · analyze · test

dart format . форматирует; flutter analyze ищет проблемы; flutter test проверяет поведение.

Обратите внимание Команды r/R работают в терминале запущенного flutter run. Изменение нативного кода требует полного перезапуска/пересборки.

Три роли виджетов в приложении

StatelessWidget

Параметры и окружение. Подходит карточке, заголовку или кнопке с callback.

StatefulWidget + State

Параметры остаются неизменяемыми, а изменяемые данные хранятся в отдельном State.

InheritedWidget

Предоставляет данные потомкам и уведомляет зарегистрированные зависимости.

Обратите внимание Это разные роли в дереве. StatefulWidget тоже неизменяем; изменяется его State.

Дальше последовательно разберём StatelessWidget, StatefulWidget и InheritedWidget.

Создаём StatelessWidget для отдельной части экрана

Dart
class Temperature extends StatelessWidget {
  const Temperature({super.key, required this.degrees});
  final int degrees;

  @override
  Widget build(BuildContext context) {
    return Text('$degrees °C',
      style: const TextStyle(fontSize: 48),
    );
  }
}
  • Конструктор принимает degrees, final-поле хранит значение, build возвращает Text.
  • Теперь в разных местах экрана можно писать Temperature(degrees: 18).
  • Родитель передаёт другое значение — виджет строит новое описание текста.

Когда выделять собственный виджет

Повторяется фрагмент

Карточка или строка нужны в нескольких местах; входные параметры делают их переиспользуемыми.

Есть самостоятельная задача

Заголовок, карточка, блок действий получают понятное имя и собственный контракт.

build трудно читать

Разделите экран по смысловым частям. Не нужно создавать класс для каждого отступа.

Обратите внимание StatelessWidget не означает «нет действий». Он может получать callback и передавать его кнопке.

Ключевые параметры содержимого

Text

style — шрифт и цвет; textAlign — выравнивание строк; maxLines и overflow — ограничение текста.

Image

Типичные ошибки layout и их причины

width игнорируется

Родитель передал tight constraints. Проверьте их до изменения размера ребёнка.

Text выходит за Row

Обычный ребёнок измерен без предела ширины. Дайте тексту конечную долю через flex.

Expanded внутри scroll

По основной оси нет конечного остатка. Уберите flex или ограничьте область.

ListView внутри Column

Viewport не получил конечную высоту. Часто список нужно обернуть в Expanded.

Когда использовать builder

FutureBuilder

Одна асинхронная операция: ожидание, ошибка, результат. Держите Future вне build.

StreamBuilder

Повторные значения потока. Ссылка на Stream должна оставаться стабильной.

ValueListenableBuilder

Локальное наблюдаемое значение: перестроить небольшой фрагмент при уведомлении.

LayoutBuilder / Builder

Первый даёт constraints, второй — context внутри нового места дерева.

Обратите внимание В builder описывают UI. Побочные эффекты, запросы и управление ресурсами принадлежат владельцу состояния.

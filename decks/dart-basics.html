Переменные /3

Ключевое слово const помечает константы. Их значения известны ещё на этапе компиляции, и их нельзя модифицировать или переопределять во время исполнения.

Ключевое слово final запрещает переопределение переменной после инициализации. Переменная, помеченная final, — не константа, просто её значение нельзя переопределить после инициализации.

Sound null safety в Dart 3

  • Начиная с Dart 3 весь код работает с sound null safety; отключить её нельзя.
  • Тип String не допускает null, а String? допускает.
  • Анализатор продвигает nullable-значение после достаточной проверки.
  • Оператор ! — утверждение разработчика и может привести к runtime-ошибке.
  • Чтение неинициализированной late-переменной также даёт runtime-ошибку.
